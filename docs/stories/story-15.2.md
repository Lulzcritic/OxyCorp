# Story 15.2: RTS Battle Viewer

**Epic:** Epic 15: Deterministic RTS Combat & Rendering
**Role:** Developer
**Goal:** I want a Three.js visualizer that reads the combat event log and plays back the battle like an RTS.

## Acceptance Criteria

1.  **Event Log Parsing**:
    - Fetch the `BattleLog` JSON generated by the backend simulation.
    - Pre-process the ticks into a timeline that can be scrubbed.

2.  **Playback Controls**:
    - Implement Play, Pause, Fast Forward (2x, 4x) controls.
    - Add a timeline scrubber to jump to specific points in the battle.

3.  **Entity Rendering**:
    - Render drones on a 3D plane (using React Three Fiber).
    - Interpolate movement between ticks so drones move smoothly across the map rather than teleporting grid-by-grid.

4.  **State Sync**:
    - Ensure HP bars and status indicators correctly update based on the current playback tick.
